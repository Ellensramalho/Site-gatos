# 🐱 Site Gatos

Projeto desenvolvido para praticar **HTML** e **CSS**.

---

 🚧 Projeto em desenvolvimento – novas melhorias e funcionalidades ainda serão adicionadas.

---

## 📖 Sobre o projeto

O **Site Gatos** é uma página web criada com temática felina, desenvolvida com o objetivo de colocar em prática conceitos de desenvolvimento front-end, estruturação de páginas e estilização.

Durante o desenvolvimento foram trabalhados conceitos como:

✨ Estrutura semântica HTML.  
✨ Organização de componentes visuais.  
✨ Estilização com CSS.
✨ Layout de páginas.
✨ Posicionamento de elementos.  
✨ Responsividade (em andamento).

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3
